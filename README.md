A visually rich personal portfolio website that tells the story of Arpit Bajpai's journey through data, AI, and intelligent systems.

## 🌌 Overview

This portfolio is designed as a sleek one-page experience with an editorial, futuristic aesthetic. It blends immersive storytelling with technical credibility, featuring:

- a cinematic hero section
- dynamic UI details and motion accents
- sections for about, journey, skills, projects, and contact
- AI guide and resume CTAs
- a clean, responsive layout for desktop and mobile

## 🧩 Project Structure

```text
portfolio-2/
├── index.html      # Main page structure and portfolio sections
├── style.css       # Visual design, theme, layout, and animation styling
├── script.js       # Interactive behaviors and UI logic
├── assets/         # Images, icons, and supporting media
├── README.md       # Project documentation
└── .gitignore      # Git ignore rules (if present)
```

## 🚀 Run Locally

Open the project directly in a browser, or serve it locally:

```bash
cd portfolio-2
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## 🎨 Customize It

- Update personal details, projects, and story content in `index.html`
- Refine theme colors, typography, spacing, and animations in `style.css`
- Adjust interactivity or behavior in `script.js`
